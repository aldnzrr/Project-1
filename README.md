# Dust la Stella — Clothing Brand Company Profile Website

Watch Website: https://aldnzrr.github.io/Project-1/

Company profile website for the local clothing label **Dust la Stella**, built with plain HTML, CSS and JavaScript (no framework, no build step). It features a 3D logo animated on scroll, a brand journey timeline, a curved product showcase and a limited-drop countdown.

## Run locally
```
npm start
```
Then open http://localhost:3000

## Deploy
Site files live in `public/`. GitHub Pages deploys that folder automatically on every push to `main`.
